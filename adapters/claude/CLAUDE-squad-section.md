# Subscription Squad default

- Automatically invoke `/subscription-squad` for every substantive coding, debugging, code review, architecture, multi-file codebase investigation, or research-synthesis task, even when the user does not name the skill. Make this routing decision before doing the substantive implementation or synthesis in the main Claude conversation.
- A task is substantive when it needs model judgment, cross-file reasoning, diagnosis, design tradeoffs, implementation logic, or evidence synthesis. Keep deterministic, trivial, and mechanical operations local.
- For substantive work, obtain at least one bounded external-worker deliverable that materially influences the result. A hello-world probe, generic opinion, duplicate restatement, or after-the-fact rubber stamp does not count.
- Follow the full installed Subscription Squad skill for route selection and acceptance. The custom `muse` agent is only the Muse relay; it is not a substitute for Cursor Grok review, native Grok Build, or Antigravity when another route fits the deliverable.
- Native Claude subagents (general-purpose, Explore, Plan, or model-pinned Opus/Sonnet agents) are never a worker route; they spend the same usage limit the squad exists to save.
- A request for higher quality ("best possible", "flawless", "maybe spawn Opus agents or idk") is not an opt-out: answer with smaller Muse packages, stronger acceptance tests, and independent external review. Say once, in one line, that native implementation agents would spend this usage limit. Implement with native agents only if the user then explicitly confirms, and still keep external review and the two-concurrent-worker cap.
- Never poll workers (`sleep`, `ps`, `kill -0`, `tail`, repeated `collect.py`). Wait for the background-task exit notification, or one background `collect.py --wait` longer than the worker timeout. Redirect worker output and keep only the runner's final JSON line; read `result.txt`, never `output.log` or raw receipts.
- Every coordinator turn re-reads the whole context. When the session is already very long, tell the user before starting another large task that a fresh session will make each turn cheaper. Near a usage limit, stop dispatching and leave a resume note: ledger and run-dir paths, what is accepted, what is open, and the next brief.
- Claude owns scoping, live web retrieval and citations, verification, integration, final acceptance, and communication with the user. In the installed skill, interpret references to the Codex coordinator or current Codex conversation as the Claude coordinator and current Claude conversation.
- Skip the squad only for trivial or mechanical work, sensitive or excluded material, explicit user opt-out, unavailable suitable routes, or when no route adds useful capacity. State the skip and reason before substantive work and repeat it in the final answer; never silently take over the full substantive task.
- User instructions, safety rules, permissions, and task scope remain controlling. Subscription Squad delegation never authorizes publishing, billing changes, purchases, external messages, or other actions the user did not request.
